# 0〜9 数字分析ツール

GitHub Pagesなどの静的サイトで動作する、ブラウザ内完結の数字分析ツールです。

## v2で追加
- 数字→次の数字の遷移分析
- 直前の数字を選択して、次に出た数字の回数・割合を表示

## データ
ブラウザのlocalStorageに保存します。外部APIやサーバーは使用しません。

## 理論値
0を1、1〜9を4として、合計37。
- 0: 1/37 = 約2.70%
- 1〜9: 4/37 = 約10.81%

## パターン
a=1,2,3
b=4,5,6
c=7,8,9
d=1,4,7
e=2,5,8
f=3,6,9

※統計的な分析であり、次に出る数字を保証・予言するものではありません。
