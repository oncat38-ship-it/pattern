# 0-9 数字分析ツール 第1版

数字ボタンを押すだけで履歴を記録し、ブラウザ内に保存します。

## 第1版の機能
- 0～9のワンクリック入力
- 一つ戻す
- 全リセット
- 数字別の出現回数・出現率
- 0を他の数字の4倍出にくいものとして理論値を計算
- a～fパターンへの分類
- 数字履歴・パターン履歴
- 直近50件の推移グラフ
- localStorageによるブラウザ内保存

## a～f
- a = 1,2,3
- b = 4,5,6
- c = 7,8,9
- d = 1,4,7
- e = 2,5,8
- f = 3,6,9

## 注意
第1版の「次の候補」は予測AIではなく、現在の実測値が理論値からどれだけ不足しているかを使った暫定表示です。
将来、遷移確率や直近データなどを使う予測方式に置き換えられる構造にしています。
